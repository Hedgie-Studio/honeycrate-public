Как обновлять manifest?
Способ через костыли:
Добавляем ссылку на файл в необходимый манифест, при этом вводим любой sha1.
Запускаем игру. Файл скачается если он отсутствует.
Перезапускаем игру. Консоль выдаст предупреждение о несовпадении sha1 мода и sha1 в манифесте, после чего выдаст актуальный sha1.
Полученный sha1 вводим в манифест.
Снова перезапускаем игру, в консоли даст предупреждение о несоответствии sha1 у json манифеста.
Вводим новый манифест json в главный manifest.json.
